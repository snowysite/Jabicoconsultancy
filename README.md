# Jabico Consultancy Portal

## Run the backend

1. Open a terminal in `jabico-backend`.
2. Run `npm install` once.
3. Run `npm start`.
4. Keep the backend terminal open. It runs on `http://localhost:4000`.

## Admin

Email: `admin@jabicoconsultancy.com`
Password: `Admin@123`

The admin login now receives a JWT from the backend. The Applications page uses the same JWT for loading applications and accepting/rejecting them.

## Important

The frontend currently expects the backend at `http://localhost:4000`. This is intentional for local testing. Before production deployment, change `API_BASE_URL` to the deployed API URL.
